--------------------------------------------------------------------------------
2.1 KINEMATICS & PARABOLIC JUMP MATH
--------------------------------------------------------------------------------
Under constant gravity $g$ and initial vertical velocity $v_0$:
- Time to apex:
  $t_{apex} = \frac{|v_0|}{g} = \frac{690}{1500} = 0.46\text{ seconds}$
- Maximum theoretical jump height:
  $h_{apex} = \frac{v_0^2}{2g} = \frac{690^2}{3000} = 158.7\text{ px}$ (Calibrated as 155 px)
- Safe step-up limit (with 15% player margin):
  $h_{safe} = 155 \times 0.85 \approx 131\text{ px}$ (Strict design rule: $\le 110\text{ px}$)
- Total flight time on level ground:
  $t_{total} = 2 \times t_{apex} = 0.92\text{ seconds}$
- Maximum horizontal travel distance at $v_x = 260\text{ px/s}$:
  $d_{max} = v_x \times t_{total} = 260 \times 0.92 = 239.2\text{ px}$
- Safe horizontal jump gap (with 15% player margin):
  $d_{safe} = 239.2 \times 0.85 \approx 203\text{ px}$ (Strict level design gap rule: $\le 145\text{ px}$)

--------------------------------------------------------------------------------
2.3 ONE-WAY PLATFORM COLLISION LOGIC
--------------------------------------------------------------------------------
One-Way platforms use a custom processCallback in Phaser Arcade physics:
```javascript
this.physics.add.collider(this.player, this.oneWayPlatforms, null, (player, plat) => {
    if (this.isDead) return false;
    const pBody = player.body;
    if (!this.isFlipped) {
        // Player is upright: only collide when falling downward and feet were previously above slab
        const prevBottom = pBody.prev.y + pBody.height;
        return (pBody.velocity.y >= 0 && prevBottom <= plat.walkTop + 16);
    } else {
        // Player is upside-down: only collide when falling upward towards ceiling slab
        const prevTop = pBody.prev.y;
        return (prevTop >= plat.walkTop - 20);
    }
}, this);
```
Benefits:
- Player can jump from underneath and pass straight through without bumping their head.
- Downward descent cleanly catches the platform surface.
- Moving between tiered platforms feels identical to classic precision platformers like Celeste.

--------------------------------------------------------------------------------
2.4 HAZARD SYSTEMS & TELEGRAPHING
--------------------------------------------------------------------------------
1. PATROL SAWS (`patrolSaw`):
   - Circular hitbox with radius $r = 36-40\text{ px}$, concentric with blade texture.
   - Sinusoidal or linear horizontal patrol back and forth with smooth turnarounds.
   - Rotates continuously at 3 deg/frame.
2. SWINGING CHAIN SAWS (`swingSaw`):
   - Anchored to ceiling via metal mounting bracket at $(x_{pivot}, y_{pivot})$.
   - Chain links rendered with procedural circular links along vector.
   - Blade position driven by harmonic pendulum physics:
     $\theta(t) = \theta_{max} \times \sin\left(\frac{2\pi t}{T}\right)$
     $x = x_{pivot} + L \sin(\theta), \quad y = y_{pivot} + L \cos(\theta)$
3. SPIKES (`spikes`):
   - Floor spike strips ($y = 600$, height $45\text{ px}$) or Ceiling spike strips ($y = 130$, pointing down).
   - Grouped with clear landing zones between strips (e.g. Twin Strips).
4. SLIDING SPIKES (`slideSpike`):
   - Retracted by default (alpha 0.25).
   - Audio warning cue + orange flash shake ($280\text{ ms}$) prior to extending.
   - Extends outward with Back.easeOut, stays lethal for active duration, then retracts.
5. FALLING PLATFORMS (`fallingPlatform`):
   - Metal platform that shakes for $500\text{ ms}$ with orange telegraph tint when stood on, then drops into abyss.
   - Respawns automatically upon checkpoint reload.
6. FALLING STALACTITE TRAPS (`decor_stalactite` with `trap: true`):
   - Ceiling stalactite decor with proximity trigger ($|x - x_{trigger}| < radius$).
   - Plays audio warning, emits ceiling dust particles, shakes for $280\text{ ms}$, then falls with quadratic acceleration ($g \approx 1400$).
   - Shatters upon hitting floor or platform.
